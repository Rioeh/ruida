快速开始

Zonalea 是锐达科技推出的操作系统。本文档帮助你完成下载、安装与基础配置。

文档内容为示例占位，正式发布前请替换为真实文档。

安装 Zonalea

1. 从下载中心获取 ISO 镜像；2. 使用工具制作启动盘；3. 从启动盘引导并按照向导安装。

# 校验镜像（示例）
sha256sum zonalea-1.0-lts.iso

命令行基础

Zonalea 提供常用命令行工具，以下为示例：

# 查看系统信息
zonalea --version

# 更新软件包
zona update

# 查看帮助
zona help

API 示例

开发者可通过 API 与 Zonalea 服务交互。以下为示例请求：

GET /api/v1/system/info
Authorization: Bearer <token>

{
  "os": "Zonalea",
  "version": "1.0 LTS",
  "status": "ok"
}
